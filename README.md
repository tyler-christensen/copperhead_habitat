# copperhead_habitat

This repository contains the data and code used to examine the spatial and environmental separation of individual- and population-level core habitats of eastern copperheads (Agkistrodon contortrix). Data include identifiers (season, individual, sex, and reproductive status) and measured habitat values at tracked snake locations. Spatial coordinates were shifted to obscure sensitive location information and to comply with New Jersey Fish and Wildlife Scientific Collecting Permit conditions. For a detailed explanation of the analytical methods used, see the manuscript titled "Episodic gregariousness leads to level-dependent core habitats: a case study in eastern copperheads (Agkistrodon contortrix)" (in preparation as of 8/15/2024).
